excerpt: 'Path partition problems on trees have found various applications. In this paper, we present an $$O(n \log n)$$ time algorithm for solving the following variant of path partition problem: sum-of-max chain partition of a tree. The problem is NP-complete for arbitrary graphs. Furthermore, we extended the algorithm to the sum-of-dominant case, in which the cost of a chain is determined by the highest-ranked vertex''s cost.'
